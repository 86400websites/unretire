## 1. Context

The owner added `Website-Development-System/` (the SOP: predevelopment worksheets + the development delivery
machine) to this repo and asked to move (Un)Retire onto it end to end. (Un)Retire is an already-built,
guest-preview Next.js site — so this is a **retrofit**, not a greenfield build. The system's own modules
explicitly support retrofit (`docs/testing-setup/00-START-HERE.md`, `docs/error-tracking/00-START-HERE.md`).

R1 executes the Setup Gate (`docs/templates/NEW-WEBSITE-SETUP-CHECKLIST.md`) adapted to an existing repo.
