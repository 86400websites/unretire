# Sprint Record — S4.3 — Paid Content + Data

Branch `claude/s4.3-paid-content`, merged 2026-08-30 as **PR #22** (`d725aea`).

## Outcome

Closes Known issues **37**, **39**, **43**. Issues **21** (schema capture) and the RLS half were found **already complete** — see below.

## 37 — the $99 course was never protected, only hidden

`CoursePlayer.tsx` is a `"use client"` component and imported `courseData.ts` directly, so **all 58 lesson video ids shipped in the JavaScript bundle of every visitor** — signed out, signed in, paid or not. The four worksheets sat in `public/assets/unretire/course/` as ordinary static files, fetchable by URL with no session. The server's entitlement check ran correctly; only its *answer* reached the browser, while the content itself was already there. The padlock was decoration over content the visitor's machine already held.

Fixed structurally: `CoursePlayer` no longer imports `courseData` at all (`import type` is erased at compile time), data arrives as a prop, and the server picks the real modules or `lockedModules()`. Worksheets moved to `src/app/learn/course/_worksheets/` behind `/api/course-worksheet`, which checks entitlement **first** and resolves a whitelisted key — the request cannot express a path, which beats sanitising one.

**Verified against a production build:** 0 of 5 paid ids in the anonymous HTML, 0 across all 10 referenced JS chunks, free preview still served, all worksheet keys 403 anonymously, old public paths 404, traversal refused. Satisfies **I2**.

## 39 — Premium was being given away

Access was granted on checkout and revoked only on `customer.subscription.deleted`, so a subscription whose renewal failed kept working. Now follows `customer.subscription.updated`. *(The pre-launch review later found this still had an unbounded `past_due` grace — Finding 3, fixed in S4.5.)*

## 43 — the one-download limit degraded to nothing

Every insert failure except `23505` fell through to the download, so a persistent failure meant unlimited downloads. Now fails **CLOSED** per §5.
