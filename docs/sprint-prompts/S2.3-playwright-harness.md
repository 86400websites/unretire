   S2.2 discipline).

## A. Diagnosis

Stage 2 has CI (S2.1) and isolated, MCP-reachable environments (S2.2) but **no way to observe a deployed Preview
behaving** — every "proof" so far is a dashboard reading or a read-only probe, and P1 is still owed because no tool
could get past Deployment Protection. This sprint installs the Launch Gate's setup half exactly as
`docs/testing-setup/SETUP-CHECKLIST.md` defines it: Playwright as a permanent repo asset, a config that carries the
sanctioned bypass by name, one smoke test, one auth-setup per role, the morning check parked disabled — and proves the
pipeline is alive end to end with a green run against a real Preview. Everything S2.5 and S5.1 do next stands on it.
