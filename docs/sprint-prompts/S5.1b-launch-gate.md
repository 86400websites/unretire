| **D-32** | Remove the Guest Preview announcement band and all user-visible "Half a Life" chrome | **Owner, 2026-09-01.** The preview period ended on its own date (31 August 2026 — D-10's designed expiry) and the site launches as a standalone product. Kept: the `/about` "Don't live half a life" quote (approved editorial copy — the book's origin story), and the non-user-visible traces already tracked as S3.2 hygiene (`package.json` name, the dead `globals.css` palette comment, the stray repo-root `page.tsx`, historical docs). |
| **D-33** | No custom SMTP at launch — Known issue 50 accepted | **Owner, 2026-09-01:** "we dont want to add SMTP, etc for now and we have already added DMARC, etc in mailchimp so we are good there." Consequence accepted: production Supabase Auth keeps the built-in mailer's **2 emails/hour project-wide** cap; the third password-reset request in an hour silently receives nothing (signups send no mail — "Confirm email" is OFF). Feature line **FM-010** therefore stays red by decision, as a recorded exception, not a pass. Mailchimp **marketing** sends are unaffected (the owner has completed Mailchimp domain authentication — SPF/DKIM/DMARC — which is what MN-002 asks for on the marketing domain). Compensating controls: reset requests are rare at launch scale; the daily `@morning` check (S5.2) plus a `docs/POST-LAUNCH-BACKLOG.md` entry to adopt custom SMTP when volume warrants. Revisit trigger: any user report of a missing reset email. |
