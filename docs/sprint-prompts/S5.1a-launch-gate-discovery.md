### Confirmed by this run

- **Known issue 1 reproduced end to end.** `/api/book-download` returns `application/json` (`route.ts:97-101`, a 500) instead of a PDF, because the master lives at `src/app/account/_book/…` and the route reads `src/app/unretire/account/_book/…`. It did **not** return 403, so authorisation is sound and only the path is wrong — a useful narrowing for S3.1.
- **Every protected boundary now has an allowed AND a denied proof on a deployed environment** — AC-010, AC-013, AC-015, IN-005. First time in the project.
- **PR-006 / invariant I3** proven directly against `unretire-test`: 2 entitlement rows, anon sees 0, one authenticated user sees exactly 1; and `entitlements` carries no INSERT/UPDATE/DELETE policy, so only the service role can write it.

### Two harness defects found and fixed (neither a site defect)

Both were tests **passing or failing for an incidental reason** — worse than an honest failure, because such a test reads as proof.

1. **The Preview bypass never reached API-style requests** (`af76f02`). `context.route()` intercepts only browser navigations, so `page.request.*` calls hit Vercel's 401 instead of the app. Five specs affected. Invisible locally — `localhost` has no deployment protection. Fixed with an `api` fixture.
2. **Two CI runs of one commit raced over shared fixture accounts** (`795d292`). The concurrency key fell back to `github.run_id` for non-PR events, so `pull_request` and `deployment_status` ran concurrently; `AC-002`'s logout calls `signOut()` at its default **`global`** scope and revoked the other run's session mid-test. Evidence: run #96 = 105/1 while its twin #97 = 104/2 at the same commit. Fixed by keying concurrency on the commit SHA.

### Deviations from the approved plan

- **AC-013 and AC-015 were NOT converted to the `api` fixture**, though the approved plan said to convert them. Implementing showed that would be wrong: a standalone `APIRequestContext` carries no cookies, so both would have lost the member's session and returned 403 for the wrong reason — `AC-013` would have stayed green while proving nothing. Both keep `page.request` to inherit the session, with comments explaining why they differ from `AC-010` a few lines above.
- **`.github/workflows/e2e-preview.yml` was edited**, which was not on this sprint's allowed-files list. Raised with the owner and approved before the edit.
