   `resolveTarget()` with `bypassPresent: true` admits ONLY `isProjectHost` regardless of `morningRun`. Confirm
   there is no path by which a bypass-bearing run resolves to `www.unretireproject.com`, `localhost`, either
   Vercel alias or any third-party host. Confirm `tests/e2e/fixtures.ts` is unchanged and still attaches the
   header only to requests whose origin equals the validated `baseURL`.

   (not a regex, not an env read); `isProduction` requires `https:`; the admission requires `flags.morningRun`.

   not an allow-list) and say whether you agree. Confirm the apex, `http://`, subdomains and look-alike hosts
